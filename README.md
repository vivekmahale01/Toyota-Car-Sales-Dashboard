# 🚗 Toyota Car Sales Dashboard | Power BI

## 📌 Project Overview

The **Toyota Car Sales Dashboard** is a modern and interactive Power BI project designed to analyze the sales performance of Toyota's top-selling vehicles.
This project focuses on **visual storytelling, UI/UX design, and interactive dashboard development** instead of traditional boring dashboards.
The dashboard provides valuable business insights through clean visuals, KPI cards, dynamic filtering, and automotive-themed design.

---

## 🚘 Cars Included

* Toyota Innova
* Toyota Hyryder
* Toyota Fortuner

---

## 🎯 Project Objectives

* Analyze Toyota car sales performance.
* Compare sales trends across multiple years.
* Identify monthly sales patterns.
* Analyze regional sales distribution.
* Build a modern and visually appealing dashboard.
* Demonstrate Power BI dashboard development skills.

---

## 📊 Key Dashboard Features

✅ Interactive Multi-Page Navigation

✅ Dynamic KPI Cards

✅ Car-wise Sales Analysis

✅ Year-wise Filtering (2019 - 2022)

✅ Region-wise Analysis

✅ Monthly Units Sold Trend

✅ Segment Analysis (Direct Sale, Pre Book, Third Party)

✅ Automotive Themed UI/UX Design

## 📈 KPIs Used

| KPI                | Description                  |

| Total Units Sold   | Total cars sold              |

## 💡 Business Insights

* Sales peak during festive months such as October and November.
* Direct Sales contribute the highest share of total sales.
* Western region generates the highest sales.
* Toyota Innova records the highest unit sales among all vehicles.
